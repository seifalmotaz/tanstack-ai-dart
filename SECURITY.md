# Security

This is an unofficial community Dart SDK for TanStack AI, not affiliated with TanStack.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting and open a draft advisory at:

https://github.com/seifalmotaz/tanstack-ai-dart/security/advisories/new

Use this private channel for sensitive reports. Do not include credentials, API
keys, customer prompts, or other private data. Provide a minimal reproduction.

Report ordinary bugs in [GitHub issues](https://github.com/seifalmotaz/tanstack-ai-dart/issues).
Ask usage questions in [Discussions](https://github.com/seifalmotaz/tanstack-ai-dart/discussions).

## What to include

- A minimal, sanitized reproduction.
- The affected Dart SDK version and package version.
- Platform and runtime details (Dart, OS, browser or VM).
- The observed impact and any conditions required to trigger it.

## Supported versions

Fixes are reviewed against the latest GitHub release only. Older versions do not
carry a separate maintenance promise. The initial release is v0.3.0; the Dart
version is independent of any npm package pin.
